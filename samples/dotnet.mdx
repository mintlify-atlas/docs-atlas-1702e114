The A2A .NET samples demonstrate three progressively advanced patterns for building Agent-to-Agent protocol-compatible agents in C# using the `A2A` and `A2A.AspNetCore` NuGet packages. `BasicA2ADemo` shows the minimal wiring needed to run an agent server and connect a client. `A2ACliDemo` shows how to bridge agents with system-level operations using a whitelist-secured command executor. `A2ASemanticKernelDemo` shows how to integrate Microsoft Semantic Kernel for AI-powered text processing. All three demos run on .NET 9 and support Windows, Linux, and macOS.

<Warning>
  All samples are for demonstration purposes only. Treat all data received from external agents as untrusted input. The CLI agent's whitelist approach is illustrative — review security implications carefully before deploying anything similar in a real environment.
</Warning>

## Prerequisites

- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- Windows, Linux, or macOS

### EchoAgent Implementation

The `EchoAgent` illustrates the minimal shape of an A2A agent in .NET. It attaches two callbacks to the `ITaskManager`: one for processing incoming messages and one for serving the AgentCard.

```csharp
using A2A;
using A2A.AspNetCore;

public class EchoAgent
{
    public void Attach(ITaskManager taskManager)
    {
        taskManager.OnMessageReceived = ProcessMessageAsync;
        taskManager.OnAgentCardQuery = GetAgentCardAsync;
    }

    private Task<Message> ProcessMessageAsync(
        MessageSendParams messageSendParams,
        CancellationToken cancellationToken)
    {
        var userText = GetTextFromMessage(messageSendParams.Message);

        var responseMessage = new Message
        {
            Role = MessageRole.Agent,
            MessageId = Guid.NewGuid().ToString(),
            ContextId = messageSendParams.Message.ContextId,
            Parts = [new TextPart { Text = $"Echo: {userText}" }]
        };

        return Task.FromResult(responseMessage);
    }

    private Task<AgentCard> GetAgentCardAsync(
        string agentUrl,
        CancellationToken cancellationToken)
    {
        return Task.FromResult(new AgentCard
        {
            Name = "Simple Echo Agent",
            Description = "A basic agent that echoes back any message you send to it.",
            Url = agentUrl,
            Version = "1.0.0",
            DefaultInputModes = ["text"],
            DefaultOutputModes = ["text"],
            Capabilities = new AgentCapabilities { Streaming = true }
        });
    }

    private static string GetTextFromMessage(Message message)
    {
        var textPart = message.Parts.OfType<TextPart>().FirstOrDefault();
        return textPart?.Text ?? "[No text content]";
    }
}
```

### EchoServer Startup (`Program.cs`)

```csharp
using A2A;
using A2A.AspNetCore;
using EchoServer;

var builder = WebApplication.CreateBuilder(args);
builder.Logging.AddConsole();
var app = builder.Build();

var taskManager = new TaskManager();
var echoAgent = new EchoAgent();
echoAgent.Attach(taskManager);

app.MapA2A(taskManager, "/");   // Registers the JSON-RPC endpoint
app.MapGet("/health", () => Results.Ok(new { Status = "Healthy" }));

app.Run("http://localhost:5001");
```

The `MapA2A` extension registers both the `/.well-known/agent.json` AgentCard endpoint and the JSON-RPC POST handler at the specified path.

### CLIAgent — Whitelist and Execution

```csharp
public class CLIAgent
{
    private static readonly HashSet<string> AllowedCommands = new()
    {
        // File operations
        "dir", "ls", "pwd", "cat", "type", "head", "tail",
        // System info
        "whoami", "date", "time", "echo",
        // Process / network
        "ps", "tasklist", "netstat", "ipconfig", "ping",
        // Dev tools
        "git", "dotnet", "node", "npm", "python"
    };

    public void Attach(ITaskManager taskManager)
    {
        taskManager.OnMessageReceived = ProcessMessageAsync;
        taskManager.OnAgentCardQuery = GetAgentCardAsync;
    }

    private async Task<string> ExecuteCommandAsync(
        string input,
        CancellationToken cancellationToken)
    {
        var (command, arguments) = ParseCommand(input);

        if (!AllowedCommands.Contains(command.ToLowerInvariant()))
        {
            return $"❌ Command '{command}' is not allowed. " +
                   $"Allowed: {string.Join(", ", AllowedCommands)}";
        }

        using var process = new Process();

        if (RuntimeInformation.IsOSPlatform(OSPlatform.Windows))
        {
            process.StartInfo.FileName = "cmd.exe";
            process.StartInfo.Arguments = $"/c {command} {arguments}";
        }
        else
        {
            process.StartInfo.FileName = "/bin/bash";
            process.StartInfo.Arguments = $"-c \"{command} {arguments}\"";
        }

        process.StartInfo.UseShellExecute = false;
        process.StartInfo.RedirectStandardOutput = true;
        process.StartInfo.RedirectStandardError = true;
        process.StartInfo.CreateNoWindow = true;

        process.Start();
        process.BeginOutputReadLine();
        process.BeginErrorReadLine();
        await process.WaitForExitAsync(cancellationToken);

        return FormatCommandResult(/* ... */);
    }
}
```

### Supported AI Functions

The `AIAgent` routes incoming messages by prefix keyword to one of four Semantic Kernel prompt invocations:

| Prefix | Function | Description |
|--------|----------|-------------|
| `summarize:` | `SummarizeTextAsync` | Condenses text to 2–3 sentences |
| `sentiment:` | `AnalyzeSentimentAsync` | Returns sentiment, confidence score, and emotions |
| `ideas:` | `GenerateIdeasAsync` | Generates 5 creative suggestions for the given topic |
| `translate:` | `TranslateTextAsync` | Translates text to Spanish (default target language) |
| `help` | `GetCapabilitiesAsync` | Lists all available functions and examples |

### AIAgent Implementation

```csharp
public class AIAgent
{
    private readonly Kernel _kernel;
    private readonly ILogger<AIAgent> _logger;

    public AIAgent(Kernel kernel, ILogger<AIAgent> logger)
    {
        _kernel = kernel;
        _logger = logger;
    }

    public void Attach(ITaskManager taskManager)
    {
        taskManager.OnMessageReceived = ProcessMessageAsync;
        taskManager.OnAgentCardQuery = GetAgentCardAsync;
    }

    private async Task<Message> ProcessMessageAsync(
        MessageSendParams messageSendParams,
        CancellationToken cancellationToken)
    {
        var userText = GetTextFromMessage(messageSendParams.Message);
        var lowerText = userText.ToLower();

        if (lowerText.StartsWith("summarize:"))
        {
            var text = userText[(userText.IndexOf(':') + 1)..].Trim();
            return await SummarizeTextAsync(text);
        }
        else if (lowerText.StartsWith("sentiment:"))
        {
            var text = userText[(userText.IndexOf(':') + 1)..].Trim();
            return await AnalyzeSentimentAsync(text);
        }
        else if (lowerText.StartsWith("ideas:"))
        {
            var topic = userText[(userText.IndexOf(':') + 1)..].Trim();
            return await GenerateIdeasAsync(topic);
        }
        else if (lowerText.StartsWith("translate:"))
        {
            var text = userText[(userText.IndexOf(':') + 1)..].Trim();
            return await TranslateTextAsync(text, "Spanish");
        }
        else
        {
            return await GetCapabilitiesAsync();
        }
    }

    private Task<AgentCard> GetAgentCardAsync(
        string agentUrl,
        CancellationToken cancellationToken)
    {
        return Task.FromResult(new AgentCard
        {
            Name = "AI Agent",
            Description = "AI-powered agent using Semantic Kernel for text processing and analysis",
            Url = agentUrl,
            Version = "1.0.0",
            DefaultInputModes = ["text"],
            DefaultOutputModes = ["text"],
            Capabilities = new AgentCapabilities { Streaming = false }
        });
    }
}
```
