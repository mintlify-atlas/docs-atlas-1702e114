The A2A **Hello World** agent is the simplest possible demonstration of the Agent-to-Agent protocol in Python. It registers an `AgentCard`, exposes a JSON-RPC endpoint over HTTP with Starlette and Uvicorn, and responds to any text message with `"Hello, World! I have received your request (…)"`. Working through this sample teaches you every structural layer you will reuse in every A2A agent you build afterwards.

## Project layout

```text
samples/python/agents/helloworld/
├── __main__.py        # Server entry-point: AgentCard, routes, Starlette app
├── agent_executor.py  # HelloWorldAgent + HelloWorldAgentExecutor
├── test_client.py     # Async client: card discovery, send, stream, extended card
└── requirements.txt   # Python dependencies
```

## `__main__.py` — server entry-point

This file wires together every A2A server primitive: skills, agent cards, the request handler, routes, and the ASGI app.

### Defining a skill

An `AgentSkill` describes one callable capability the agent exposes to clients. Clients use the skill list in the `AgentCard` to understand what they can ask.

```python
skill = AgentSkill(
    id='echo_bot',
    name='Echo Bot',
    description='An example agent that acknowledges client request and responds with a "Hello World" message.',
    input_modes=['text/plain'],
    output_modes=['text/plain'],
    tags=['a2a', 'echo-example'],
    examples=['hi', 'how are you'],
)
```

A second, non-public skill is also defined for authenticated users only:

```python
extended_skill = AgentSkill(
    id='echo_bot_super_mode',
    name='Echo Bot (Super Mode)',
    description='An extended version of Echo Bot that responds with extra enthusiasm!',
    tags=['a2a', 'echo-example', 'extended'],
    examples=['super hi', 'give me a super hello'],
)
```

### Defining the public AgentCard

The `AgentCard` is the agent's self-description, served at `/.well-known/agent.json` so clients can discover it without any prior knowledge of the agent's capabilities.

```python
public_agent_card = AgentCard(
    name='Hello World Agent',
    description='Just a hello world agent',
    version='0.0.1',
    default_input_modes=['text/plain'],
    default_output_modes=['text/plain'],
    capabilities=AgentCapabilities(streaming=True, extended_agent_card=True),
    supported_interfaces=[
        AgentInterface(
            protocol_binding='JSONRPC',
            url='http://127.0.0.1:9999',
            protocol_version='1.0',
        )
    ],
    skills=[skill],
)
```

<Note>
  The `extended_agent_card=True` capability flag tells clients that this agent
  can return a richer card — with additional skills — when the client
  authenticates.
</Note>

### Extended AgentCard for authenticated users

```python
extended_agent_card = AgentCard(
    name='Hello World Agent - Extended Edition',
    description='The full-featured hello world agent for authenticated users.',
    version='0.0.2',
    default_input_modes=['text/plain'],
    default_output_modes=['text/plain'],
    capabilities=AgentCapabilities(streaming=True, extended_agent_card=True),
    supported_interfaces=[
        AgentInterface(
            protocol_binding='JSONRPC',
            url='http://127.0.0.1:9999',
            protocol_version='1.0',
        )
    ],
    skills=[skill, extended_skill],
)
```

### Wiring the request handler and routes

`DefaultRequestHandler` connects the `AgentExecutor` with the in-memory task store and both agent cards:

```python
request_handler = DefaultRequestHandler(
    agent_executor=HelloWorldAgentExecutor(),
    task_store=InMemoryTaskStore(),
    agent_card=public_agent_card,
    extended_agent_card=extended_agent_card,
)
```

Routes are split into two groups — one for serving the card itself, and one for all JSON-RPC traffic:

```python
routes = []
routes.extend(create_agent_card_routes(public_agent_card))
routes.extend(create_jsonrpc_routes(request_handler, '/'))
```

### Starting the ASGI server

```python
app = Starlette(routes=routes)
uvicorn.run(app, host='127.0.0.1', port=9999)
```

<Tip>
  You can swap Starlette for FastAPI, or Uvicorn for any other ASGI server,
  without changing any A2A logic.
</Tip>

## `agent_executor.py` — task execution

This file contains two classes: the inner `HelloWorldAgent` (pure business logic) and `HelloWorldAgentExecutor` (the A2A adapter). It imports from `a2a.helpers` and `a2a.server.agent_execution`:

```python
from a2a.helpers import (
    get_message_text,
    new_task_from_user_message,
    new_text_message,
    new_text_part,
)
from a2a.server.agent_execution import AgentExecutor, RequestContext
from a2a.server.events import EventQueue
from a2a.server.tasks import TaskUpdater
from a2a.types import TaskState
```

### HelloWorldAgent

The core agent has no A2A knowledge at all — it simply returns a greeting string:

```python
class HelloWorldAgent:
    """Hello World Agent."""

    async def invoke(self, user_request: str) -> str:
        """Invoke the Hello World agent to generate a response."""
        return f'Hello, World! I have received your request ({user_request})'
```

### HelloWorldAgentExecutor — execute

`execute` is called for every `message/send` or `message/stream` request. It follows a five-step pattern that every A2A executor reuses:

```python
class HelloWorldAgentExecutor(AgentExecutor):
    """Test AgentProxy Implementation."""

    def __init__(self) -> None:
        self.agent = HelloWorldAgent()

    async def execute(
        self,
        context: RequestContext,
        event_queue: EventQueue,
    ) -> None:
        """Process user request."""
        # 1. Collect a task from request context
        if context.current_task:
            task = context.current_task
        else:
            # 1.1 If there is no task, create one and add it to the event queue
            task = new_task_from_user_message(context.message)
            await event_queue.enqueue_event(task)

        # 2. Update task status in EventQueue using TaskUpdater
        task_updater = TaskUpdater(
            event_queue=event_queue, task_id=task.id, context_id=task.context_id
        )
        await task_updater.update_status(
            state=TaskState.TASK_STATE_WORKING,
            message=new_text_message('Processing request...'),
        )

        # 3. Collect user request and invoke the agent
        query = get_message_text(context.message)
        if query:
            result = await self.agent.invoke(user_request=query)
        else:
            result = 'No text input is provided!'

        # 4. Add the generated response as an artifact
        await task_updater.add_artifact(parts=[new_text_part(text=result, media_type='text/plain')])

        # 5. Mark task completed
        await task_updater.update_status(
            state=TaskState.TASK_STATE_COMPLETED,
            message=new_text_message('Request is completed!'),
        )
```

<Info>
  **Task state flow:** `submitted` → `working` → `completed`. The `event_queue`
  carries every state transition to the client, enabling both streaming and
  non-streaming responses from the same code path.
</Info>

### HelloWorldAgentExecutor — cancel

Cancellation is not implemented in this minimal sample; the method raises `NotImplementedError` to make that explicit:

```python
    async def cancel(self, context: RequestContext, event_queue: EventQueue) -> None:
        """Raise exception as cancel is not supported."""
        raise NotImplementedError('Cancel is not supported.')
```

## `test_client.py` — interacting with the agent

The test client demonstrates four operations: fetching the public card, sending a non-streaming message, sending a streaming message, and fetching the extended card.

### Resolving the AgentCard

```python
import httpx
from a2a.client import A2ACardResolver

async with httpx.AsyncClient() as httpx_client:
    resolver = A2ACardResolver(
        httpx_client=httpx_client,
        base_url='http://127.0.0.1:9999',
    )
    public_agent_card = await resolver.get_agent_card()
```

### Non-streaming message

The `send_message` function in `test_client.py` creates a non-streaming client and sends a request:

```python
from a2a.client import ClientConfig, create_client
from a2a.helpers import new_text_message
from a2a.types import Role, SendMessageRequest

config = ClientConfig(streaming=False)
client = await create_client(agent=public_agent_card, client_config=config)

message = new_text_message(text_query, role=Role.ROLE_USER)
request = SendMessageRequest(message=message)

async for chunk in client.send_message(request):
    print(chunk)

await client.close()
```

### Streaming message

```python
client_config = ClientConfig(streaming=True)
client = await create_client(agent=public_agent_card, client_config=client_config)

async for chunk in client.send_message(request):
    print(chunk)

await client.close()
```

### Fetching the extended card

Authenticated clients can call `get_extended_agent_card` to receive the card with the additional hidden skills:

```python
from a2a.types import GetExtendedAgentCardRequest

extended_card = await client.get_extended_agent_card(GetExtendedAgentCardRequest())
```

## Container deployment

You can also run the Hello World agent as a container:

<Steps>
  <Step title="Navigate to the agent directory">
    ```bash
    cd samples/python/agents/helloworld
    ```
  </Step>
  <Step title="Build the image">
    ```bash
    podman build . -t helloworld-a2a-server
    ```
    Docker is also supported: replace `podman` with `docker`.
  </Step>
  <Step title="Run the container">
    ```bash
    podman run -p 9999:9999 helloworld-a2a-server
    ```
  </Step>
  <Step title="Verify with the CLI host">
    ```bash
    cd samples/python/hosts/cli
    uv run . --agent http://127.0.0.1:9999
    ```
  </Step>
</Steps>

<Warning>
  Treat every piece of data received from an external agent — AgentCard fields,
  messages, artifact text — as untrusted input. Passing unvalidated agent
  responses directly into LLM prompts can expose your application to prompt
  injection attacks.
</Warning>
