Google's [Agent Development Kit (ADK)](https://github.com/google/adk-python) provides a high-level framework for building agents backed by Gemini models. The A2A repository includes two ADK-based samples that illustrate complementary patterns: a **currency conversion agent** with optional traceability extensions and structured JSON output, and an **expense reimbursement agent** that uses multi-turn form-filling to collect missing details from the caller. Both agents are wrapped with an `AgentExecutor` and served as standard A2A servers.

## Sample overview

<CardGroup cols={2}>
  <Card title="ADK Currency Agent" icon="coins">
    Converts currencies via the Frankfurter API. Supports a traceability extension that records each tool call's trajectory for evaluation in non-production environments.
  </Card>
  <Card title="ADK Expense Reimbursement Agent" icon="receipt">
    Processes employee expense claims. Returns a structured form to the client when required fields (date, amount, purpose) are missing, then completes reimbursement once the form is returned.
  </Card>
</CardGroup>

## Prerequisites

Both samples share the same requirements:

- Python 3.9 or higher (Python 3.10+ recommended)
- [uv](https://docs.astral.sh/uv/) package manager
- A Google API key with access to Gemini models

### `agent.py` — ADK LlmAgent and tools

The ADK `LlmAgent` is constructed with a set of async Frankfurter tool functions and a Pydantic output schema. Using `output_schema` forces the model to always return structured JSON, which the executor then parses to determine the next task state.

```python
from google.adk.agents import LlmAgent
from pydantic import BaseModel, Field

class AgentResponse(BaseModel):
    message: str = Field(
        description='Message generated by the agent as response for user input'
    )
    status: Literal['completed', 'input-required', 'failed'] = Field(
        description='Status of the agent response'
    )

root_agent = LlmAgent(
    name='currency_agent',
    model='gemini-3-flash-preview',
    description='Currency Conversion agent',
    instruction=(
        "You are an agent that helps with user's currency conversions. "
        'Use available tools to help with the conversion. '
        'For currency conversions, do not assume target currencies. '
        'If user did not specify the target currency, ask for it.'
    ),
    tools=[
        get_latest_rates,
        get_historical_rates,
        get_time_series_rates,
        get_available_currencies,
    ],
    output_schema=AgentResponse,
)
```

The four Frankfurter tools cover all common query types:

```python
async def get_latest_rates(base: str = 'EUR', symbols: str | None = None) -> dict:
    """Retrieve the latest exchange rates."""
    async with httpx.AsyncClient() as client:
        params = {}
        if base:
            params['base'] = base
        if symbols:
            params['symbols'] = symbols
        response = await client.get(
            'https://api.frankfurter.dev/v1/latest', params=params
        )
        response.raise_for_status()
        return response.json()

async def get_time_series_rates(
    start_date: str,
    end_date: str | None = None,
    base: str | None = None,
    symbols: str | None = None,
) -> dict:
    """Retrieve exchange rates over a time period."""
    ...
```

### `agent_executor.py` — A2A adapter and traceability

`CurrencyAgentExecutor` receives an ADK `Runner` instance and streams events from it. When the client includes the traceability extension URI in the request header, the executor collects each `FunctionCall` and `FunctionResponse` event into a `ResponseTrace` object and attaches it to the final task metadata.

```python
class CurrencyAgentExecutor(AgentExecutor):
    def __init__(self, runner: Runner):
        self._runner = runner

    async def execute(
        self, context: RequestContext, event_queue: EventQueue
    ) -> None:
        context_id = context.context_id
        user_id = _resolve_user_id(context)

        query = context.get_user_input()
        content = types.Content(
            role='user', parts=[types.Part.from_text(text=query)]
        )

        response_trace = None
        if TRACEABILITY_EXTENSION_URI in context.requested_extensions:
            if os.getenv('ENV', 'production') != 'production':
                context.add_activated_extension(TRACEABILITY_EXTENSION_URI)
                response_trace = ResponseTrace()

        await self.ensure_session(user_id, context_id)

        task = context.current_task
        if not task:
            task = new_task(context.message)
            await event_queue.enqueue_event(task)

        updater = TaskUpdater(event_queue, task.id, task.context_id)

        async for event in self._runner.run_async(
            user_id=user_id, session_id=context_id, new_message=content
        ):
            if response_trace:
                self._process_trace_events(event, response_trace)

            if event.is_final_response():
                await self._process_final_response(
                    event, updater, response_trace, task
                )

    async def ensure_session(self, user_id: str, context_id: str) -> None:
        """Ensure an ADK session exists for the given user and context ID."""
        session = await self._runner.session_service.get_session(
            app_name=self._runner.app_name,
            user_id=user_id,
            session_id=context_id,
        )
        if session is None:
            await self._runner.session_service.create_session(
                app_name=self._runner.app_name,
                user_id=user_id,
                session_id=context_id,
            )

    async def cancel(self, context: RequestContext, event_queue: EventQueue) -> None:
        raise NotImplementedError('Cancellation is not supported')
```

<Info>
  The executor uses `_resolve_user_id(context)` to bind ADK sessions to
  authenticated users. When the request is unauthenticated, it falls back to
  `'a2a_user'`. The A2A `context_id` is intentionally never used as the ADK
  `user_id` to prevent session hijacking by a malicious caller.
</Info>

### `main.py` — server entry-point

The entry-point loads the `AgentCard` from `agent_card.json`, constructs an ADK `Runner`, and wires everything into `A2AStarletteApplication`:

```python
runner = Runner(
    app_name=root_agent.name,
    agent=root_agent,
    session_service=InMemorySessionService(),
)

request_handler = DefaultRequestHandler(
    agent_executor=CurrencyAgentExecutor(runner),
    task_store=task_store,
)

a2a_app = A2AStarletteApplication(
    agent_card=agent_card, http_handler=request_handler
)
app = a2a_app.build()
```

### Traceability extension

To receive tool trajectory data, include the extension URI in the request header:

```http
POST http://localhost:10999
Content-Type: application/json
X-A2A-Extensions: https://github.com/a2aproject/a2a-samples/extensions/traceability/v1
```

### What the agent does

When a user submits an expense request, the agent:

1. Calls `create_request_form()` to generate a form with any known fields pre-filled.
2. Returns the form as a `DataPart` with `TaskState.input_required`, prompting the client or its user to fill in missing fields.
3. On the follow-up message with the completed form, validates all required fields and calls `reimburse()`.
4. Returns the `request_id` and `status: approved` as a completed artifact.

### `agent.py` — form tools and ReimbursementAgent

The agent uses three tools to manage the reimbursement lifecycle:

```python
def create_request_form(
    date: Optional[str] = None,
    amount: Optional[str] = None,
    purpose: Optional[str] = None,
) -> dict[str, Any]:
    """Create a request form for the employee to fill out."""
    request_id = 'request_id_' + str(random.randint(1000000, 9999999))
    request_ids.add(request_id)
    return {
        'request_id': request_id,
        'date': '<transaction date>' if not date else date,
        'amount': '<transaction dollar amount>' if not amount else amount,
        'purpose': '<business justification/purpose of the transaction>'
        if not purpose
        else purpose,
    }


def return_form(
    form_request: dict[str, Any],
    tool_context: ToolContext,
    instructions: Optional[str] = None,
) -> dict[str, Any]:
    """Returns a structured JSON object indicating a form to complete."""
    tool_context.actions.skip_summarization = True
    tool_context.actions.escalate = True
    form_dict = {
        'type': 'form',
        'form': {
            'type': 'object',
            'properties': {
                'date':       {'type': 'string', 'format': 'date',   'title': 'Date'},
                'amount':     {'type': 'string', 'format': 'number', 'title': 'Amount'},
                'purpose':    {'type': 'string',                     'title': 'Purpose'},
                'request_id': {'type': 'string',                     'title': 'Request ID'},
            },
            'required': list(form_request.keys()),
        },
        'form_data': form_request,
        'instructions': instructions,
    }
    return json.dumps(form_dict)


def reimburse(request_id: str) -> dict[str, Any]:
    """Reimburse the amount of money to the employee for a given request_id."""
    if request_id not in request_ids:
        return {'request_id': request_id, 'status': 'Error: Invalid request_id.'}
    return {'request_id': request_id, 'status': 'approved'}
```

`return_form` sets `tool_context.actions.escalate = True`, which causes ADK to surface the tool response directly to the A2A layer without additional LLM summarization.

The underlying `ReimbursementAgent` is constructed using `LlmAgent` with `LiteLlm` as the model backend:

```python
from google.adk.agents.llm_agent import LlmAgent
from google.adk.models.lite_llm import LiteLlm

class ReimbursementAgent:
    SUPPORTED_CONTENT_TYPES = ['text', 'text/plain']

    def _build_agent(self) -> LlmAgent:
        LITELLM_MODEL = os.getenv('LITELLM_MODEL', 'gemini/gemini-2.0-flash-001')
        return LlmAgent(
            model=LiteLlm(model=LITELLM_MODEL),
            name='reimbursement_agent',
            tools=[create_request_form, reimburse, return_form],
            ...
        )
```

### `agent_executor.py` — handling form responses

The executor distinguishes between three content types returned by the agent stream:

```python
class ReimbursementAgentExecutor(AgentExecutor):
    def __init__(self):
        self.agent = ReimbursementAgent()

    async def execute(self, context: RequestContext, event_queue: EventQueue) -> None:
        query = context.get_user_input()
        task = context.current_task
        if not task:
            task = new_task(context.message)
            await event_queue.enqueue_event(task)
        updater = TaskUpdater(event_queue, task.id, task.context_id)

        async for item in self.agent.stream(query, task.context_id):
            is_task_complete = item['is_task_complete']

            if not is_task_complete:
                # Intermediate working status
                await updater.update_status(
                    TaskState.working,
                    new_agent_text_message(item['updates'], task.context_id, task.id),
                )
                continue

            if isinstance(item['content'], dict):
                # Form response — set task state to input_required
                if 'response' in item['content'] and 'result' in item['content']['response']:
                    data = json.loads(item['content']['response']['result'])
                    await updater.update_status(
                        TaskState.input_required,
                        new_agent_parts_message(
                            [Part(root=DataPart(data=data))],
                            task.context_id,
                            task.id,
                        ),
                        final=True,
                    )
                    continue
                # Unexpected dict structure — mark as failed
                await updater.update_status(
                    TaskState.failed,
                    new_agent_text_message('Reaching an unexpected state', task.context_id, task.id),
                    final=True,
                )
                break

            # Text response — task is complete
            await updater.add_artifact(
                [Part(root=TextPart(text=item['content']))], name='form'
            )
            await updater.complete()
            break
```

<Tip>
  The `DataPart` in the `input_required` message carries the full JSON Schema
  of the form. A UI-capable client can render this as an interactive form;
  a headless client simply returns the completed fields as a text message in
  the next turn.
</Tip>

## Comparison of the two ADK samples

| | ADK Currency Agent | ADK Expense Reimbursement |
|---|---|---|
| **LLM** | `gemini-3-flash-preview` via `LlmAgent` | `gemini/gemini-2.0-flash-001` via `LiteLlm` |
| **Multi-turn** | Yes — asks for target currency | Yes — requests missing form fields |
| **Output type** | Text artifact | Text artifact or `DataPart` form |
| **Traceability** | Yes (opt-in via extension header) | No |
| **Default port** | 10999 | 10002 |
| **Session management** | `CurrencyAgentExecutor.ensure_session()` | Inline in `ReimbursementAgent.stream()` |

<Warning>
  Never pass field values from an externally provided `DataPart` directly into
  an LLM prompt without sanitization. Treat all inbound form data as untrusted
  input, even when it originates from a known agent.
</Warning>
