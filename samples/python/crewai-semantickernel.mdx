This page covers two A2A Python agent samples that demonstrate how different LLM orchestration frameworks integrate with the A2A protocol. The **CrewAI agent** generates images from text prompts using Google Gemini, while the **Semantic Kernel travel agent** coordinates a multi-agent pipeline for trip planning and currency conversion with real-time streaming and conversational memory.

---

## CrewAI Image Generation Agent

The CrewAI agent accepts a text description from a client, passes it to a Google Gemini image generation model through a CrewAI `@tool`, and returns the resulting image as a binary `FilePart` artifact. An in-memory image cache (`InMemoryCache`) allows subsequent requests to reference and modify images generated earlier in the same session.

### Directory layout

```text
samples/python/agents/crewai/
├── agent.py           # ImageGenerationAgent + generate_image_tool (CrewAI)
├── agent_executor.py  # ImageGenerationAgentExecutor
├── __main__.py        # AgentCard, A2AStarletteApplication startup
├── in_memory_cache.py # Session-scoped image cache
└── Containerfile
```

### What it does

```text
A2A Client → A2AStarletteApplication → ImageGenerationAgentExecutor
                                               ↓
                                   ImageGenerationAgent.invoke()
                                               ↓
                                   CrewAI Crew.kickoff()
                                               ↓
                                   generate_image_tool → Gemini API
                                               ↓
                                   FilePart artifact returned to client
```

### Prerequisites

- Python 3.12 or higher
- [uv](https://docs.astral.sh/uv/) package manager
- A Google API key with access to `gemini-2.0-flash-exp` (or Vertex AI credentials)

### `agent.py` — ImageGenerationAgent

#### CrewAI tool

The `@tool` decorator wraps the Gemini call so CrewAI's planner knows when and how to invoke it. The tool builds a text instruction tuple (including an instruction to ignore unrelated reference images), retrieves any existing image from the session cache as a reference, and calls the Gemini multimodal API:

```python
@tool('ImageGenerationTool')
def generate_image_tool(
    prompt: str, session_id: str, artifact_file_id: str = None
) -> str:
    """Image generation tool that generates images or modifies a given image based on a prompt."""
    if not prompt:
        raise ValueError('Prompt cannot be empty')

    client = genai.Client()
    cache = InMemoryCache()

    text_input = (
        prompt,
        'Ignore any input images if they do not match the request.',
    )

    # Retrieve an existing image from the cache to use as a reference
    ref_image = None
    try:
        session_image_data = cache.get(session_id)
        if artifact_file_id:
            ref_image_data = session_image_data[artifact_file_id]
        else:
            latest_key = list(session_image_data.keys())[-1]
            ref_image_data = session_image_data[latest_key]
        ref_bytes = base64.b64decode(ref_image_data.bytes)
        ref_image = Image.open(BytesIO(ref_bytes))
    except Exception:
        ref_image = None

    contents = [text_input, ref_image] if ref_image else text_input

    response = client.models.generate_content(
        model='gemini-2.0-flash-exp',
        contents=contents,
        config=types.GenerateContentConfig(
            response_modalities=['Text', 'Image']
        ),
    )

    for part in response.candidates[0].content.parts:
        if part.inline_data is not None:
            data = Imagedata(
                bytes=base64.b64encode(part.inline_data.data).decode('utf-8'),
                mime_type=part.inline_data.mime_type,
                name='generated_image.png',
                id=uuid4().hex,
            )
            session_data = cache.get(session_id)
            if session_data is None:
                cache.set(session_id, {data.id: data})
            else:
                session_data[data.id] = data
            return data.id

    return -999999999
```

#### Agent, task, and crew construction

```python
class ImageGenerationAgent:
    SUPPORTED_CONTENT_TYPES = ['text', 'text/plain', 'image/png']

    def __init__(self):
        if os.getenv('GOOGLE_GENAI_USE_VERTEXAI'):
            self.model = LLM(model='vertex_ai/gemini-2.0-flash')
        elif os.getenv('GOOGLE_API_KEY'):
            self.model = LLM(
                model='gemini/gemini-2.0-flash',
                api_key=os.getenv('GOOGLE_API_KEY'),
            )

        self.image_creator_agent = Agent(
            role='Image Creation Expert',
            goal=(
                "Generate an image based on the user's text prompt. If the prompt is "
                'vague, ask clarifying questions. Focus on interpreting the user\'s '
                'request and using the Image Generator tool effectively.'
            ),
            backstory=(
                'You are a digital artist powered by AI. You specialize in taking '
                'textual descriptions and transforming them into visual '
                'representations using a powerful image generation tool.'
            ),
            verbose=False,
            allow_delegation=False,
            tools=[generate_image_tool],
            llm=self.model,
        )

        self.image_creation_task = Task(
            description=(
                "Receive a user prompt: '{user_prompt}'.\n"
                'Analyze the prompt and identify if you need to create a new image '
                'or edit an existing one. Use the Image Generator tool for image '
                'creation or modification.'
            ),
            expected_output='The id of the generated image',
            agent=self.image_creator_agent,
        )

        self.image_crew = Crew(
            agents=[self.image_creator_agent],
            tasks=[self.image_creation_task],
            process=Process.sequential,
            verbose=False,
        )

    def invoke(self, query, session_id) -> str:
        """Kickoff CrewAI and return the response."""
        artifact_file_id = self.extract_artifact_file_id(query)
        inputs = {
            'user_prompt': query,
            'session_id': session_id,
            'artifact_file_id': artifact_file_id,
        }
        response = self.image_crew.kickoff(inputs)
        return response
```

<Note>
  CrewAI does not natively support streaming. The `stream` method on
  `ImageGenerationAgent` raises `NotImplementedError`, so the A2A server is
  configured with `AgentCapabilities(streaming=False)`.
</Note>

### `agent_executor.py` — A2A adapter

The executor calls `agent.invoke()` synchronously (inside the async context), then retrieves the generated `Imagedata` from the cache and enqueues a completed `Task` event with the image bytes as a `FilePart`:

```python
class ImageGenerationAgentExecutor(AgentExecutor):
    def __init__(self) -> None:
        self.agent = ImageGenerationAgent()

    async def execute(
        self,
        context: RequestContext,
        event_queue: EventQueue,
    ) -> None:
        error = self._validate_request(context)
        if error:
            raise ServerError(error=InvalidParamsError())

        query = context.get_user_input()
        result = self.agent.invoke(query, context.context_id)

        data = self.agent.get_image_data(
            session_id=context.context_id, image_key=result.raw
        )
        if data and not data.error:
            parts = [
                FilePart(
                    file=FileWithBytes(
                        bytes=data.bytes,
                        mime_type=data.mime_type,
                        name=data.id,
                    )
                )
            ]
        else:
            parts = [
                Part(root=TextPart(text=data.error if data else 'failed to generate image'))
            ]

        await event_queue.enqueue_event(
            completed_task(
                context.task_id,
                context.context_id,
                [new_artifact(parts, f'image_{context.task_id}')],
                [context.message],
            )
        )

    async def cancel(self, request: RequestContext, event_queue: EventQueue) -> Task | None:
        raise ServerError(error=UnsupportedOperationError())
```

## Semantic Kernel Travel Agent

The Semantic Kernel agent implements a **multi-agent travel planner** using three `ChatCompletionAgent` instances: a top-level `TravelManagerAgent` that delegates to a `CurrencyExchangeAgent` (with a Frankfurter plugin) and an `ActivityPlannerAgent`. All three are wired using SK's agent-as-plugin pattern. The outer agent maintains `ChatHistoryAgentThread` across turns, providing in-memory conversational context.

### Directory layout

```text
samples/python/agents/semantickernel/
├── agent.py           # SemanticKernelTravelAgent + CurrencyPlugin + ResponseFormat
├── agent_executor.py  # SemanticKernelTravelAgentExecutor
├── __main__.py        # AgentCard, server startup
├── .envexample        # Environment variable template
└── Containerfile
```

### What it does

```text
A2A Client → SemanticKernelTravelAgentExecutor
                    ↓
           SemanticKernelTravelAgent.stream()
                    ↓
           TravelManagerAgent (SK ChatCompletionAgent)
              ↙                           ↘
CurrencyExchangeAgent               ActivityPlannerAgent
(CurrencyPlugin → Frankfurter API)   (itinerary recommendations)
```

### `agent.py` — multi-agent pipeline

#### CurrencyPlugin

The Frankfurter exchange-rate call is wrapped as a `@kernel_function` so that Semantic Kernel can expose it as a plugin to `CurrencyExchangeAgent`:

```python
class CurrencyPlugin:
    """A simple currency plugin that leverages Frankfurter for exchange rates."""

    @kernel_function(
        description='Retrieves exchange rate between currency_from and currency_to using Frankfurter API'
    )
    def get_exchange_rate(
        self,
        currency_from: Annotated[str, 'Currency code to convert from, e.g. USD'],
        currency_to: Annotated[str, 'Currency code to convert to, e.g. EUR or INR'],
        date: Annotated[str, "Date or 'latest'"] = 'latest',
    ) -> str:
        try:
            response = httpx.get(
                f'https://api.frankfurter.app/{date}',
                params={'from': currency_from, 'to': currency_to},
                timeout=10.0,
            )
            response.raise_for_status()
            data = response.json()
            if 'rates' not in data or currency_to not in data['rates']:
                return f'Could not retrieve rate for {currency_from} to {currency_to}'
            rate = data['rates'][currency_to]
            return f'1 {currency_from} = {rate} {currency_to}'
        except Exception as e:
            return f'Currency API call failed: {e!s}'
```

#### Streaming with intermediate message handling

The `stream` method uses `agent.invoke_stream()` with an `on_intermediate_message` callback to detect when the agent makes plugin (function) calls. This drives the `working` status updates that flow back to the A2A client:

```python
    async def stream(
        self,
        user_input: str,
        session_id: str,
    ) -> AsyncIterable[dict[str, Any]]:
        await self._ensure_thread_exists(session_id)

        plugin_notice_seen = False
        plugin_event = asyncio.Event()
        text_notice_seen = False
        chunks: list[StreamingChatMessageContent] = []

        async def _handle_intermediate_message(message: 'ChatMessageContent') -> None:
            nonlocal plugin_notice_seen
            if not plugin_notice_seen:
                plugin_notice_seen = True
                plugin_event.set()

        async for chunk in self.agent.invoke_stream(
            messages=user_input,
            thread=self.thread,
            on_intermediate_message=_handle_intermediate_message,
        ):
            if plugin_event.is_set():
                yield {
                    'is_task_complete': False,
                    'require_user_input': False,
                    'content': 'Processing function calls...',
                }
                plugin_event.clear()

            if any(isinstance(i, StreamingTextContent) for i in chunk.items):
                if not text_notice_seen:
                    yield {
                        'is_task_complete': False,
                        'require_user_input': False,
                        'content': 'Building the output...',
                    }
                    text_notice_seen = True
                chunks.append(chunk.message)

        if chunks:
            yield self._get_agent_response(sum(chunks[1:], chunks[0]))
```

### `agent_executor.py` — A2A adapter

The executor converts the three-valued stream output (`working`, `input_required`, `completed`) into the corresponding A2A event types:

```python
class SemanticKernelTravelAgentExecutor(AgentExecutor):
    def __init__(self):
        self.agent = SemanticKernelTravelAgent()

    async def execute(self, context: RequestContext, event_queue: EventQueue) -> None:
        query = context.get_user_input()
        task = context.current_task
        if not task:
            task = new_task(context.message)
            await event_queue.enqueue_event(task)

        async for partial in self.agent.stream(query, task.context_id):
            require_input = partial['require_user_input']
            is_done = partial['is_task_complete']
            text_content = partial['content']

            if require_input:
                await event_queue.enqueue_event(
                    TaskStatusUpdateEvent(
                        status=TaskStatus(
                            state=TaskState.input_required,
                            message=new_agent_text_message(
                                text_content, task.context_id, task.id
                            ),
                        ),
                        final=True,
                        context_id=task.context_id,
                        task_id=task.id,
                    )
                )
            elif is_done:
                await event_queue.enqueue_event(
                    TaskArtifactUpdateEvent(
                        append=False,
                        context_id=task.context_id,
                        task_id=task.id,
                        last_chunk=True,
                        artifact=new_text_artifact(
                            name='current_result',
                            description='Result of request to agent.',
                            text=text_content,
                        ),
                    )
                )
                await event_queue.enqueue_event(
                    TaskStatusUpdateEvent(
                        status=TaskStatus(state=TaskState.completed),
                        final=True,
                        context_id=task.context_id,
                        task_id=task.id,
                    )
                )
            else:
                await event_queue.enqueue_event(
                    TaskStatusUpdateEvent(
                        status=TaskStatus(
                            state=TaskState.working,
                            message=new_agent_text_message(
                                text_content, task.context_id, task.id
                            ),
                        ),
                        final=False,
                        context_id=task.context_id,
                        task_id=task.id,
                    )
                )
```

## Side-by-side comparison

| | CrewAI Image Agent | Semantic Kernel Travel Agent |
|---|---|---|
| **Framework** | CrewAI + Google Gemini | Semantic Kernel (Azure/OpenAI) |
| **Task type** | Image generation | Travel planning + currency |
| **Streaming** | No (`streaming=False`) | Yes (`message/stream`) |
| **Multi-turn** | No | Yes (ChatHistoryAgentThread) |
| **Output type** | `FilePart` (image bytes) | Text artifact |
| **Sub-agents** | Single CrewAI Agent | TravelManager → Currency + Activity |
| **Default port** | 10001 | 10020 |
| **Memory** | In-memory image cache | In-memory ChatHistoryAgentThread |

<Warning>
  Both agents treat all external input as potentially untrusted. Never forward
  unvalidated agent output directly into LLM prompts — doing so exposes your
  application to prompt injection attacks.
</Warning>
