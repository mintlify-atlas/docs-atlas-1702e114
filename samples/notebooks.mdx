## A2A Evaluation

**File:** `notebooks/a2a_evaluation.ipynb`

This notebook demonstrates how to evaluate a Reimbursement A2A Agent using **Vertex AI Evaluation** services. It runs the agent entirely in memory — no external server deployment is required — making it straightforward to iterate on agent logic and immediately measure quality.

### What you'll build

A complete evaluation pipeline for a multi-step booking/reimbursement agent:

1. **RouterAgent** — classifies user intent (`BOOK_FLIGHT`, `BOOK_HOTEL`, or `NONE`)
2. **BookingAgentExecutor** — delegates to the router and returns structured responses
3. **Evaluation harness** — sends a test dataset through the agent and scores responses with Vertex AI metrics (`coherence`, `groundedness`, `tool-call accuracy`)

### Sample: streaming a message through the in-memory handler

```python
async def send_message(query: str = "hi"):
    task_id = None
    context_id = None

    user_message = Message(
        role=Role.user,
        parts=[Part(root=TextPart(text=query))],
        message_id=str(uuid.uuid4()),
        task_id=task_id,
        context_id=context_id,
    )
    params = MessageSendParams(message=user_message)
    response_stream = request_handler.on_message_send_stream(params=params)

    async for ev in response_stream:
        pp.pprint(ev.model_dump(exclude_none=True))

await send_message("hey, could you help book my trip")
```

## Task vs. Message

**File:** `notebooks/task_vs_message.ipynb`

This notebook is a focused conceptual explainer. It illustrates the difference between the two primary A2A exchange primitives — **messages** and **tasks** — using runnable code examples that demonstrate when each is appropriate and how the protocol handles them differently.

### What you'll learn

- When a `message/send` call returns a `Message` (stateless, single-turn) versus a `Task` (stateful, multi-turn)
- How task state (`submitted` → `working` → `completed` / `input_required` / `failed`) is tracked
- How `TaskStatusUpdateEvent` and `TaskArtifactUpdateEvent` carry progress and output
- How a requesting agent decides whether to resume an existing task or start a new one

### Sample: routing agent that produces tasks or messages

The notebook defines a `RouterAgent` backed by Gemini 2.5 Flash with a structured output schema:

```python
from enum import Enum
from pydantic import BaseModel
from typing import Optional

class RouterActionType(str, Enum):
    NONE = "NONE"
    BOOK_FLIGHT = "BOOK_FLIGHT"
    BOOK_HOTEL = "BOOK_HOTEL"

class RouterOutput(BaseModel):
    message: str
    next_step: RouterActionType
    next_step_input: Optional[str] = None
```

A `BookingAgentExecutor` wraps this router and chooses whether to emit a plain message (for `NONE` intents) or create a task (for booking intents):

```python
class BookingAgentExecutor(AgentExecutor):
    """Reimbursement AgentExecutor Example."""

    def __init__(self) -> None:
        self.router_agent = RouterAgent()

    async def execute(
        self,
        context: RequestContext,
        event_queue: EventQueue,
    ) -> None:
        query = context.get_user_input()
        task = context.current_task
        router_output = await self.router_agent.run(query, str(uuid.uuid4()))
        ...
```

## Running Notebooks Locally

If you prefer to run any of the notebooks outside of a managed cloud environment, use `uv` to create an isolated Python environment with all dependencies.

<Steps>
  <Step title="Install uv">
    If `uv` is not already installed, follow the [official uv installation guide](https://docs.astral.sh/uv/getting-started/installation/).
  </Step>

  <Step title="Clone the repository and navigate to notebooks">
    ```bash
    git clone https://github.com/a2aproject/a2a-samples.git
    cd a2a-samples/notebooks
    ```
  </Step>

  <Step title="Install Jupyter and the A2A SDK">
    ```bash
    uv pip install jupyter google-adk a2a-sdk google-cloud-aiplatform httpx
    ```
  </Step>

  <Step title="Set your Google Cloud credentials">
    <Tabs>
      <Tab title="Vertex AI (recommended)">
        ```bash
        export GOOGLE_GENAI_USE_VERTEXAI=TRUE
        export GOOGLE_CLOUD_PROJECT=your_project_id
        export GOOGLE_CLOUD_LOCATION=us-central1
        gcloud auth application-default login
        ```
      </Tab>
      <Tab title="Google AI Studio API Key">
        ```bash
        export GOOGLE_API_KEY=your_api_key_here
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Launch Jupyter and open a notebook">
    ```bash
    uv run jupyter notebook
    ```

    Open any `.ipynb` file from the `notebooks/` directory in the Jupyter interface.
  </Step>
</Steps>

<Tip>
  Each notebook's first code cell contains a `%pip install` magic that will install any remaining dependencies directly into the running kernel, so you don't need to pre-install everything manually.
</Tip>
