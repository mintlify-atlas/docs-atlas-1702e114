Agent2Agent (A2A) is an open, language-agnostic protocol that gives AI agents a common language. Whether you're building with LangGraph, CrewAI, Google ADK, Semantic Kernel, or a custom stack, A2A lets your agents discover each other's capabilities, send tasks, stream real-time updates, and exchange multi-modal content — all over standard HTTP.

## Why A2A?

Modern AI applications are rarely a single model. They compose multiple specialized agents — a retrieval agent, a code-generation agent, a scheduling agent — that need to hand work off to each other reliably. Without a shared protocol, every integration is bespoke wiring.

A2A provides:

- **Discovery** — Agents publish an `AgentCard` at `/.well-known/agent.json` describing their skills, input/output modes, and supported transports.
- **Standardized messaging** — All communication is JSON-RPC 2.0 over HTTP, with a small, well-defined method set (`message/send`, `message/stream`, `tasks/get`, `tasks/cancel`).
- **Streaming** — Server-Sent Events let agents push incremental status updates to clients in real time.
- **Multi-turn tasks** — Tasks have explicit states (`submitted`, `working`, `input-required`, `completed`, `failed`) so long-running, interactive workflows are first-class.
- **Multi-modal content** — Messages carry `text`, `file`, and `data` parts, so agents can exchange rich content beyond plain text.
- **Extensibility** — A layered extension system allows teams to add routing (AGP), identity (Secure Passport), observability (Traceability), and more without breaking base-protocol compatibility.

## How It Works

<Steps>
  <Step title="Define an AgentCard">
    Declare your agent's identity, skills, and capabilities. The card is served at `/.well-known/agent.json` so any client can discover what your agent does.
  </Step>
  <Step title="Implement an AgentExecutor">
    Subclass `AgentExecutor` and implement `execute()`. Inside, use `TaskUpdater` to move the task through its lifecycle and emit artifacts when the work is done.
  </Step>
  <Step title="Start the server">
    Wire `create_agent_card_routes()` and `create_jsonrpc_routes()` into any ASGI framework (Starlette, FastAPI) and run with Uvicorn.
  </Step>
  <Step title="Connect a host">
    Point the CLI host or a multi-agent host at your server's URL. The host reads the AgentCard, sends tasks, and displays results.
  </Step>
</Steps>
