The Agent2Agent (A2A) quickstart walks you through launching the canonical helloworld agent server and communicating with it from a Python test client. The helloworld sample uses no external LLM — it echoes your input — making it the fastest possible path to observing the full A2A request/response lifecycle on your local machine.

<Note>
  This quickstart uses the Python SDK (`a2a-sdk==1.1.0`) and `uv` as the package manager. The server runs on `http://127.0.0.1:9999` by default.
</Note>

## Prerequisites

- Python 3.10 or higher
- [uv](https://docs.astral.sh/uv/) package manager

<Steps>

### Install uv

`uv` is a fast Python package and project manager that handles virtual environments and dependency resolution automatically.

<CodeGroup>
```bash macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```powershell Windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
</CodeGroup>

Verify the installation:

```bash
uv --version
```

### Navigate to the helloworld agent

Clone the repository (or navigate to it if you already have it):

```bash
git clone https://github.com/a2aproject/a2a-samples.git
cd a2a-samples/samples/python/agents/helloworld
```

The directory contains four files:

| File | Purpose |
|---|---|
| `__main__.py` | Builds the `AgentCard`, wires routes, starts the Uvicorn server |
| `agent_executor.py` | Implements `AgentExecutor` — processes requests and manages task state |
| `test_client.py` | Async test client demonstrating card resolution, non-streaming, and streaming calls |
| `requirements.txt` | Pins `a2a-sdk==1.1.0`, `uvicorn`, `pytest`, `sse-starlette` |

### Start the helloworld agent server

In your first terminal, from the `helloworld` directory:

```bash
uv run .
```

`uv` creates an isolated virtual environment, installs the pinned dependencies from `requirements.txt`, and runs `__main__.py`. You should see:

```text
INFO:     Started server process [...]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:9999 (Press CTRL+C to quit)
```

The server publishes the following AgentCard at `http://127.0.0.1:9999/.well-known/agent.json`:

```json

  "description": "Just a hello world agent",
  "version": "0.0.1",
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["text/plain"],
  "capabilities": {
    "streaming": true,
    "extendedAgentCard": true
  },
  "supportedInterfaces": [
    {
      "protocolBinding": "JSONRPC",
      "url": "http://127.0.0.1:9999",
      "protocolVersion": "1.0"
    }
  ],
  "skills": [
    {
      "id": "echo_bot",
      "name": "Echo Bot",
      "description": "An example agent that acknowledges client request and responds with a \"Hello World\" message.",
      "inputModes": ["text/plain"],
      "outputModes": ["text/plain"],

      "examples": ["hi", "how are you"]

```

### Run the test client

Open a **second terminal**, navigate to the same directory, and run:

```bash
cd a2a-samples/samples/python/agents/helloworld
uv run test_client.py
```

The test client performs four operations in sequence:

1. Resolves the public AgentCard from `/.well-known/agent.json`
2. Sends a non-streaming `message/send` request
3. Sends a streaming `message/stream` request
4. Fetches the authenticated extended AgentCard

The underlying JSON-RPC request for each `message/send` call looks like this:

```json
{
  "id": "12113c25-b752-473f-977e-c9ad33cf4f56",
  "jsonrpc": "2.0",
  "method": "message/send",
  "params": {
    "message": {
      "kind": "message",
      "messageId": "120ec73f93024993becf954d03a672bc",
      "parts": [
        {
          "kind": "text",
          "text": "Hi there!"
        }
      ],
      "role": "user"
    }
  }
}
```

Here is the relevant excerpt from `test_client.py` that builds and sends this request:

```python
from a2a.client import ClientConfig, create_client
from a2a.helpers import new_text_message
from a2a.types import Role, SendMessageRequest

config = ClientConfig(streaming=False)
client = await create_client(agent=public_agent_card, client_config=config)

message = new_text_message(text_query, role=Role.ROLE_USER)
request = SendMessageRequest(message=message)

async for chunk in client.send_message(request):
    print(chunk)
```

And for streaming:

```python
client_config = ClientConfig(streaming=True)
client = await create_client(agent=public_agent_card, client_config=client_config)

async for chunk in client.send_message(request):
    print(chunk)
```

The task progresses through three states you can observe in the history:

1. **submitted** — task is registered
2. **working** — executor is processing; interim `Processing request...` message attached
3. **completed** — final artifact `Hello, World! I have received your request (...)` is available

## What Just Happened?

<Accordion title="Step-by-step internals">
  1. `uv run .` invoked `__main__.py`, which constructed an `AgentCard`, registered it on a `Starlette` ASGI app at `/.well-known/agent.json`, and mounted JSON-RPC routes at `/`.
  2. `test_client.py` used `A2ACardResolver` to `GET /.well-known/agent.json` and deserialise the card.
  3. `create_client(agent=public_agent_card, ...)` read `supportedInterfaces[0].url` to determine the JSON-RPC endpoint.
  4. `client.send_message(request)` serialised a `SendMessageRequest` to JSON-RPC and `POST`-ed it to `http://127.0.0.1:9999/`.
  5. `DefaultRequestHandler` routed the call to `HelloWorldAgentExecutor.execute()`.
  6. The executor created a task, pushed a `working` status update, called `HelloWorldAgent.invoke()`, attached the response as an artifact, and pushed a `completed` status update — all via `EventQueue`.
  7. The server serialised the completed `Task` object and returned it as the JSON-RPC result.
</Accordion>

## Optional: Interactive CLI Host

The repository also ships a CLI host that lets you chat interactively with any A2A-compliant agent. While the helloworld server is running:

```bash
cd a2a-samples/samples/python/hosts/cli
uv run . --agent http://127.0.0.1:9999
```

Type any message and press Enter. Use `exit` to quit.
